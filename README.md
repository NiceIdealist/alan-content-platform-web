# alan-content-platform-web

alan-content-platform 的前端项目，基于 Next.js（App Router）+ TypeScript 构建。

## 开发

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看效果，编辑 `src/app/page.tsx` 会自动热更新。

## 构建

```bash
npm run build
npm run start
```

## 目录结构

```
src/app/    # App Router 页面与布局
public/     # 静态资源
```
